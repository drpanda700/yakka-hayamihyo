# 薬価早見表

**[👉 ブラウザで開く（インストール不要）](https://ユーザー名.github.io/yakka-hayamihyo/)**

薬価収載の **12,381品目** の薬価・供給状況・薬効分類を、その場で検索できるツールです。
HTMLファイル1つで動作し、インターネットに接続していなくても使えます。

> ⚠️ 収録データは **2026年7月時点** のものです。薬価改定・供給状況の変化により実際と異なる場合があります。
> 保険請求・処方の判断には、必ず最新の公式情報をご確認ください。

---

## できること

| 機能 | 内容 |
|---|---|
| 🔍 検索 | 商品名・成分名・薬効分類で横断検索（全角/半角どちらでもヒット） |
| 💊 薬価 | 薬価基準収載品目リスト（令和8年6月12日適用）の全12,381品目 |
| 🚚 供給状況 | 安定 11,128 / 限定出荷 728 / 出荷停止 525（2026年7月7日時点）<br>限定出荷・停止品目は理由と解除見込みも表示 |
| 🖩 薬剤費計算 | 1日量 × 日数 × 負担割合（1〜3割）で患者負担の概算を表示 |
| 🔄 データ更新 | 厚労省の最新Excelを読み込ませれば自分で最新化できます |

内訳：内用薬 7,051 / 注射薬 3,473 / 外用薬 1,857

## 使い方

### そのままブラウザで使う（おすすめ）

上部のリンクを開くだけです。スマートフォンでも動きます。

### 手元にダウンロードして使う

1. [index.html](index.html) を開き、右上の「Download raw file」ボタンで保存
2. 保存したファイルをダブルクリック（Microsoft Edge / Google Chrome 推奨）

ネット接続のない診察室や、USBメモリに入れて持ち運ぶ使い方ができます。

## データの更新

薬価も供給状況も変わります。以下のペースでの更新をおすすめします。

| 対象 | 頻度のめやす | 入手先 |
|---|---|---|
| 薬価リスト | 薬価改定・追補のたび（年数回） | [薬価基準収載品目リスト（厚生労働省）](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/0000078916.html) |
| 供給状況 | 月1回程度（流行期は増やしても可） | [医療用医薬品供給状況報告（厚生労働省）](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/iryou/kouhatu-iyaku/04_00003.html) |

ダウンロードしたExcelを、アプリ内の「📥 薬価リスト取込」「🚚 供給状況を更新」ボタンから読み込ませるだけです。列の対応は自動で判定します。

詳しい手順は [運用マニュアル](運用マニュアル.docx) をご覧ください。
