1. このアプリについて

厚生労働省の公式データをもとに、薬価・先発/後発区分・供給状況を院内で素早く確認するためのツールです。URLを開くだけで使え、ファイルを保存すればインターネット接続なしでも動作します。

項目内容
薬価データ薬価基準収載品目リスト(令和8年6月12日適用・厚労省) 全12,381品目
供給状況供給状況報告(2026年7月7日版・厚労省)を反映済み。安定11,128 / 限定出荷728 / 出荷停止525(照合率97.6%)
効能欄供給状況報告の「薬効分類」(解熱鎮痛消炎剤、去たん剤など)を自動転記済み。薬効からの検索も可
内訳内用薬 7,051 / 注射薬 3,473 / 外用薬 1,857
動作環境Microsoft Edge / Google Chrome など。スマートフォンでも動作
保存使ったパソコンのブラウザに自動保存(パソコンごと・データ版ごとに別管理)
限定出荷・出荷停止の品目は、メモ欄に理由と解除見込みも表示されます(例:【供給】需要増 / 未定)。画面上部に限定出荷・出荷停止の合計品目数が常時表示されます。

オフラインで使いたいとき

ネット接続のない診察室やUSBメモリで持ち運びたい場合は、アプリのページで Ctrl+S(Macは Command+S)を押してHTMLファイルとして保存してください。保存したファイルをダブルクリックすれば、接続なしで同じように使えます。

2. 日常の使い方

2-1. 薬を探す

  • 画面上部の検索欄に、商品名・成分名・薬効分類の一部を入力します(例:「アムロジピン」「カロナール」「去たん」)。全角・半角どちらでもヒットします。
  • 「内用薬 / 注射薬 / 外用薬」のボタンで剤区分を絞り込めます。
  • 「供給:」の横のボタンで「限定出荷」「出荷停止」の薬だけを一覧できます。
  • 列見出し(薬品名・薬価・供給)をクリックすると並べ替えできます。

2-2. 各行のボタン

ボタン機能
🖩 電卓薬剤費のめやす計算。1日量×日数×負担割合(1〜3割)で患者負担の概算を表示
🔗 リンクその薬の添付文書をWeb検索(インターネット接続時のみ)
✎ 鉛筆編集。効能・メモ(卸情報や代替薬)・供給状況などを書き込める
🗑 ゴミ箱その品目を削除
薬剤費計算は薬剤費のみの概算です。調剤料・管理料等の加算や端数処理により、実際の窓口負担額とは異なります。

3. データ更新の運用(重要)

薬価と供給状況は変わります。以下のスケジュールで更新してください。

対象頻度のめやすアプリのボタン
薬価リスト薬価改定・追補のたび(年数回)📥 薬価リスト取込
供給状況月1回(流行期は週1回など増やしてよい)🚚 供給状況を更新

ダウンロード先

対象入手先
薬価リスト医療保険が適用される医薬品について(厚生労働省)
最新の適用日の「薬価基準収載品目リスト」からExcelを入手
供給状況医療用医薬品供給状況報告(厚生労働省)
一覧表Excelを入手(毎日更新)
リンクが開けない場合検索:「薬価基準収載品目リスト 厚生労働省」/「医療用医薬品供給状況報告 厚生労働省」。役所のURLは組織改編等で変わることがあります

3-1. 薬価リストの更新手順(改定のたび)

  1. 念のため「CSV出力」でバックアップを取る(手入力した効能・メモを残すため)。
  2. 上記リンクから最新の適用日のExcel(内用薬・注射薬・外用薬)をダウンロード。
  3. 「薬価リスト取込」ボタンで1つ目のファイルを選択。プレビューで見出し行と列対応(自動推定)を確認。
  4. 取込方法は1ファイル目「全て置き換える」、2・3ファイル目は「いまのデータに追記する」を選択して実行。
  5. 画面左上の登録品目数が1万2千件前後になっていれば成功。
「全て置き換える」を実行すると、手入力した効能・メモ・供給状況もリセットされます。必ず手順1のバックアップを先に行ってください。

3-2. 供給状況の更新手順(月1回)

  1. 上記リンクから最新のExcelをダウンロード(元データは毎日更新)。
  2. 「供給状況を更新」ボタンでファイルを選択。列の対応(YJコード・品名・出荷対応の状況)は自動推定されるので確認して実行。
  3. 「ファイルに載っていない登録品目は『安定』にする」にチェックが入っていることを確認して実行。
  4. 完了すると「照合◯品目/限定出荷◯・出荷停止◯」と表示され、画面上部にも集計が出ます。
  • 照合はYJコード完全一致 → 品名一致 → 成分・規格グループ(コード先頭9桁)の順で自動判定します。供給状況と同時に、薬効分類(効能欄)と限定出荷の理由・解除見込み(メモ欄)も最新化されます。
  • 届出品目一覧との照合結果であり、地域の卸の在庫状況とは異なる場合があります。重要な薬は卸への確認も併用してください。

4. データの保存と他のパソコンへの引き継ぎ

  • 自動保存は「パソコンごと」です。受付PCで書いた内容は診察室PCには自動反映されません。
  • 引き継ぎ手順: 編集した側で「CSV出力」→ CSVをUSBに保存 → もう一方のPCで「薬価リスト取込」→「全て置き換える」でCSVを取込。
  • 月1回程度、「CSV出力」したファイルをUSBや院内サーバーに保管しておくと、PC入れ替え時も安心です。
  • 新しい版のアプリに差し替えた場合、自動保存はデータ版ごとに別管理のため、新版は必ず新しい埋め込みデータから始まります。旧版で手入力した内容を引き継ぎたいときは、旧版で「CSV出力」→新版で「薬価リスト取込」してください。

5. 困ったとき

症状対処
保存したファイルがダブルクリックで開かないファイルを右クリック →「プログラムから開く」→ Edge または Chrome を選択
取込プレビューで列の対応がずれている各項目のプルダウンで正しい列(例: 品名→H列)を選び直してから実行
取込後「照合できた品目がありません」と出る見出し行の選択(1行目/2行目…)と、コード・品名・供給状況の列指定を確認
「自動保存容量を超えました」と出るその場では使えるが保存されない。閉じる前に必ず「CSV出力」で保存し、次回起動時に取込
編集した内容が消えた/おかしくなった最後に保存したCSVを「全て置き換える」で取込。CSVがない場合は薬価リストを再取込
供給状況が全部「不明」になっている画面下部の「全件削除」→ ページ再読み込み(F5)で初期データに戻る
全部やり直したい画面下部の「全件削除」→ ページ再読み込み(F5)

6. 注意事項

  • 本アプリの薬価・供給状況は、取込時点の厚労省公表データに基づく参考情報です。保険請求や重要な判断の際は、必ず最新の公式情報(薬価基準収載品目リスト、供給状況報告、添付文書)をご確認ください。
  • 画面上部の注意書き欄に「初期データ: ◯◯適用」と表示されます。どの時点のデータかはここで確認できます。
  • 入力・編集したデータは利用者のブラウザ内にのみ保存され、外部に送信されることはありません。
  • 出典・ライセンス・免責事項の詳細は、アプリ画面下部の「ℹ 情報・出典・ライセンス」からご確認いただけます。
